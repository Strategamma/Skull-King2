# Skull King

Decadence Arcade phone-first pirate card game. `game/` is the self-contained production package for https://github.com/Strategamma/Skull-King. `public/` is the earlier design prototype; do not deploy it. Root `npm run dev` starts the live package; `npm run preview` explicitly starts the old prototype.

Architecture: dependency-light DOM/CSS client, original dimensional raster artwork, Node + ws authoritative WebSocket service. Same-origin `/socket` by default; `game/config.js` can point separate static hosting to a Render `wss://…/socket` endpoint. Install manifest and service worker cache the shell; multiplayer needs the server. Render blueprint includes a persistent disk with DATA_DIR=/var/data. Atomic JSON room snapshots survive restarts on persistent storage. Never expose the data directory or tokens.

Rooms: 2–10 seats, five-letter English codes, accountless editable names, private random resume tokens, all-human ready gate, host controls, disconnect grace/countdown, host transfer, temporary bot takeover or permanent kick/replacement, rematch. `arcadeName` fragment is only an untrusted prefill. Room actions validate host/seat authority; revision checks reject stale gameplay actions.

Rules: ten rounds; deal min(round, deck capacity/player count), repeat maximum deal when needed. Base/full expansion decks; sealed bids capped at actual deal, simultaneous reveal. Engine resolves ordinary cards, sea creatures, Locker, Plank before winner/bonuses, Volley extra play/final-trick skip, optional pirate powers, First Mate captured powers in played order. Mary house rule privately reveals target hand and forces/preselects its chosen card next trick; unavailable throughout round 10. Sea creatures preserve established lead suit per user-selected FAQ. Only Harry may use his power after the final trick. See `docs/RULES_SOURCES.md`; unusual Plank/no-suit fallback uses black trump then highest remaining number. Two-seat mode uses actual seated hands without the physical ghost-hand variant.

UI: suit-colored cards everywhere, red pirate/blue Mermaid frames, underlined 6/9, tap for ability/swipe legal play, explicit modes, public Tigress role, upright plays beside owners, horizontal Volley pair. Mint active-turn avatar differs from gold current-leader border. Turn chime/haptics have saved controls and visibility-aware deduplication. Final round celebrates the winner with a staged pirate reveal, finite gold shower and original synthesized sea-jig fanfare, then ledger underneath; round history uses tables. Sound respects mute/visibility; reduced motion disables decoration.

Verification: root `npm test` runs rules, bots, engine full-match simulations and room/privacy/recovery tests. `npm --prefix game run check` validates runtime syntax. Browser QA must cover actual create/join/bid/play/power/score/reconnect flows and narrow/desktop screenshots. Hosted Render, physical phones, installed PWA and background alerts require separate validation. Never equate local simulations with deployed gameplay. Artwork publication requires user authorization (deployment requested in this session).
