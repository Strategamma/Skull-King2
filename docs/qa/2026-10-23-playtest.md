# Local preview playtest · 2026-10-23

Scope: dependency-free local preview at localhost:3000, in-app browser. This is not a full-game or multiplayer certification.

## Findings and fixes

- P2 · Keyboard focus disappeared after choosing/locking bids and advancing ability steps. Reproduce: choose a bid, then press Tab; focus previously returned to the page body. UI rerenders now restore focus to the selected bid, next bidding control, or new ability heading. Verified through private lock, all-player reveal, and First Mate's full nine-step sequence.
- P2 · Bendt could be declined after the private draw was revealed. Reproduce: open Bendt, reveal drawn cards, then Decline. Optional refusal is now offered only before the power starts. Exactly two discards remain required. Declined powers now report “Power declined” instead of “Power resolved”.
- P2 · Settings unexpectedly remained open across home/table navigation. Reproduce: open gear, return home, reopen table. Home now closes settings and resets aria-expanded; retested.
- Accessibility/teaching: native overlays now receive a heading label, opening a new overlay resets old scroll, the ability library provides How to play, and playing a card moves keyboard focus to a remaining card.

## Evidence

- Syntax checks and all 18 unit tests pass.
- Browser: rejected off-suit Yellow 14 leaves ten-card hand intact; Black 9 moves once, reduces hand to nine and blocks subsequent plays.
- Bidding: locked bids stay hidden until every sample seat locks; 0 is accepted; waiting count reaches reveal.
- Ability review: First Mate decline-all and all six captured pirates complete; Bendt exact-two confirmation and Mary player/unseen-card sequence exercised.
- Responsive: 320×568 and 390×703 phone layouts; 1280×800 desktop. Seat panels checked at 2/3/4/6/10 seats: no overlap or horizontal page overflow. Ten cards remain visible at 320px. Standings uses horizontal scrolling on narrow phones.
- Join-code input strips nonletters and uppercases; sound toggles on/off. Browser reported no console errors in the tested paths.
- Screenshots: assets/concepts/qa-table-320.jpg and qa-table-desktop.jpg.

## Remaining limits

Private rooms, real turns, full trick/effect resolution, recovery, bots and offline support are not implemented. Bidding's “Back to playing preview” intentionally returns to sample data rather than continuing a match. Abilities use illustrative eligibility and outcomes. Real device installs, touch gestures in this pass, cross-browser behavior, reduced-motion emulation and network gameplay were not verified. Very small table-card labels still require tap-to-enlarge for comfortable reading; fitting ten seats and ten hand cards is a visual tradeoff.
