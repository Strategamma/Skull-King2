# Animation and recovery feedback · 2026-10-24

## Implemented

- Match identity survives persistence/resume and changes for rematch. Older saved matches receive an identity on load.
- Pure `FeedbackTracker` separates actual changes from renders/acknowledgments. Initial/reconnected/hidden snapshots establish a quiet baseline. Event state and animations are bounded, cancel on context changes, and reuse elapsed time across harmless rerenders.
- Accepted play/deal content arrival, bid reveal, leader and round emphasis; brief localized creature/Locker overlays. Hit areas stay stationary. One game sound per snapshot batch; rejected plays no longer make a successful-play swish.
- Persistent removed/cancelled/destroyed/rank-void markers and suit-neutralization, plus a scrollable current-trick explanation that does not push the hand down. Final scores retain final-trick explanations. Capture bonuses are explicitly provisional.
- Engine summaries cover Plank, sea creatures, Locker, Volley, next leader and resolved/declined pirate powers. First Mate decisions identify source portraits. Mary selections, discarded identities and privately inspected cards are excluded from public feedback.
- Separate lifecycle and recovery areas, host/takeover/return/removal notices, timed connected/reveal confirmations, elapsed wait, Retry now and Leave. Lobby and table seats show disconnect countdowns; recovery preserves phase-1 no-replay behavior.
- Explicit turn-alert test respects saved settings and reports unsupported/unavailable channels. Reduced motion retains static explanations; hidden-page/navigation cancellation suppresses stale motion and celebration replay.
- Service-worker shell includes the new module with a cache-version bump.

The in-app browser animation-introspection method was unavailable, so static screenshots and visible transitions are not presented as complete animation timing evidence. Pure event tests cover replay prevention; a full browser burst/hidden-page rerun remains open. Rejection and timeout were rerun after presentation integration, as recorded above.

The large trick-result panel still obscures some table cards; the planned phase-3 result-tray redesign is separate. No hosted deployment or publication was performed. Client/server must ship together for structured event metadata and acknowledgment support.
